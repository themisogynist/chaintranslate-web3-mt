# Dataset provenance and attribution

Source: ethereum.org contributors, https://github.com/ethereum/ethereum-org-website

Pinned revision: fb3514bd596848d74500429c43b955c999af839b

English/French pairs are derived from matching keys in `src/intl/en/` and `src/intl/fr/`. Each retained pair includes the key, original file and links to both source-language files. Changes include HTML removal, entity decoding, whitespace normalization, length filtering, duplicate removal and selection of a bounded subset.
